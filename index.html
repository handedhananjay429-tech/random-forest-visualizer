Random Forest Visualizer

A Random Forest trains many decision trees on different random bootstrap samples of the data, with each tree also picking a random subset of features at each split. The final prediction is the majority vote across all trees — reducing overfitting and producing a smoother, more accurate decision boundary than any single tree. Hover over the canvas to see how each tree votes!
